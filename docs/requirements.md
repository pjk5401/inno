# 확정 요구사항 및 화면 구성

작성 기준: 2026-10-28 사용자와 합의한 내용. 서비스 목적은 출석 전용이며 행사명·일반 안내문 설정은 제외한다.

## 목적과 운영 규모

축제 3일간 시간표에 등록된 각 수업을 별도 출석 단위로 관리한다. 종이 명단 검색과 서명으로 생기는 대기열을 줄이고 학생 스스로 출석을 완료하게 한다. 한 수업 50~70명, 동시간대 약 100~200명 집중을 예상한다. 학생에게 가입·로그인·명단 선택을 요구하지 않는다. 조교는 문제 발생 학생만 처리한다.

## 역할과 권한

|기능|학생|조교|관리자|
|---|---|---|---|
|QR 접속·본인 정보 입력·서명·위치 제출|가능|학생 흐름 체험 가능|학생 흐름 체험 가능|
|다른 학생 명단·서명 조회|불가|가능|가능|
|일정·명단·인정 구역·현장 QR 관리|불가|가능|가능|
|출석 조회·정정·엑셀·변경 이력|불가|가능|가능|
|테스트 제어·초기화|불가|가능|가능|
|계정·권한·전역 출석 정책|불가|불가|가능|
|VM 설치·삭제·백업·복구|불가|불가|서버 운영자용 스크립트|

관리자·조교는 사전 발급 계정을 사용한다. 학생 명단은 회원 계정이 아니다. 운영·테스트 계정 저장소도 분리하며 최초 관리자는 관리 스크립트로 양쪽에 생성한다. 이후 계정 변경은 각 환경에서 수행한다.

## 출석 규칙

- 수업 시작 10분 전부터 시작 15분 후까지(경계 포함) 출석.
- 시작 15분 후를 초과하고 종료 시각 전까지 지각.
- 종료 시각부터 자동 접수 불가. 종료까지 유효한 기록이 없으면 결석.
- 종료 전 미제출은 미출석으로 표시. 수동 결석 정정은 별도 명시.
- 유효한 현장 QR 접속 후 5분 작성. 제출을 서버가 받은 시점 기준.
- 작성 시간이 남아 있어도 수업 종료가 우선한다.
- 같은 학생도 수업마다 별도 제출. 같은 수업은 중복 생성·덮어쓰기 금지.
- 학번과 이름은 선택한 수업 명단에 정확히 일치해야 한다. 앞뒤 공백은 제거한다.
- QR은 운영/테스트별 고정 접속 URL이다. PNG 다운로드·인쇄를 지원하며 시간·테스트 초기화와 무관하게 유지된다. 접속 시 새 5분 작성 세션을 발급한다.
- 세션이 만료되면 같은 브라우저에서 새 QR을 스캔해 작성 내용을 복원한다. 입력 복원은 해당 탭의 sessionStorage 기반이며 다른 브라우저 앱으로 열린 경우에는 보장되지 않는다.
- 화면 입력 초안은 서버 제출 전 일시 보존하며 완료 시 삭제한다. 기기 공유에 대비해 1시간 이상 된 초안은 복원하지 않는다.

## 현장 확인

관리자가 아니라 조교도 지도 중심과 반경을 설정할 수 있다. 층·강의실은 구분하지 않고 학과 건물과 주변을 인정한다. 제출할 때 위치 권한을 받아 좌표·정확도·측정 시각을 검사한다. 계속 추적하지 않는다. 실제 위치 정보가 없거나 오래됐거나 오차가 너무 크면 재측정·조교 문의를 안내한다.

위치 확인으로 구역 밖 출석을 억제하지만 고정 QR은 누구나 공유할 수 있고 위치 조작·친구 정보 대리 입력을 완전히 차단하지 못한다. MAC 주소 수집이나 회원가입은 사용하지 않는다. 모바일 장치 고유 식별을 보장한다고 표시하지 않는다.

## 학생 화면

1. 고정 QR 접속: 로그인 없이 5분 작성 세션 발급. QR 자체는 만료되지 않는다.
2. 출석 작성: 수업 선택, 학번·이름·서명. 소속 선택은 숨긴다. 작성 시간 제한은 유지하되 남은 시간은 표시하지 않는다. 수업은 서버 판정 시각 기준 시작 전 접수 구간부터 종료 직전까지 활성 수업만 표시한다. 작성 중 10초마다 목록을 갱신하며 서버가 제출 시 재검사한다. 전체 명단 비공개.
3. 위치 확인·제출: 위치 권한·오류·재시도. 저장 확인 전 완료 표시 금지.
4. 완료: 수업, 학번·이름, 출석·지각, 인정 시각.
5. 오류: 시간 만료·명단 불일치·위치 실패·통신 실패 해결 안내.

## 조교 화면

학생 화면에는 학번 변경 기능을 제공하지 않는다. 학번 제한 등 예외 상황은 학생이 조교를 찾아가 설명하고, 조교가 수업·명단에서 해당 학생을 찾아 현장 확인 후 수동 출석과 사유를 기록한다. 브라우저의 최초 등록 학번은 유지한다.

로그인, 일자별 현황, 수업 등록·수정, 수업별 명단·검색·필터, 엑셀 업로드(파일→열 연결→검증/미리보기→확정), 개별 명단 수정, 인정 구역, 고정 QR 인쇄·PNG 저장, 출석 상세·서명·정책 증빙, 수동 정정·사유, 엑셀 두 종류, 변경 이력, 테스트 제어.

명단 재업로드는 추가·수정 방식이다. 파일에 없는 기존 학생과 기존 출석을 자동 삭제하지 않는다. 수업 목록·상세에서 관리자와 조교가 수업 삭제를 할 수 있다. 삭제될 명단·출석·서명 수를 확인하고 수업명과 사유를 입력한 뒤 삭제한다. 해당 수업의 명단·출석·서명과 완료 세션을 제거하며 다른 수업·브라우저 학번 등록·변경 이력은 보존한다. 확인 이후 자료가 변경되면 다시 확인해야 한다. 기존 백업은 자동 변경하지 않는다. 수동 정정은 기존 서명을 유지하며 없는 서명을 생성하지 않는다. 동시에 수정하면 오래된 화면의 덮어쓰기를 차단한다.

## 관리자 화면

모든 조교 화면 + 계정 발급·비활성화·역할·비밀번호 초기화 + 출석 정책 + 저장 공간·백업 목록. 행사명·일반 안내 설정 없음. 서버 백업·복구는 권한 있는 VM 운영자가 메뉴 스크립트로 수행하고 웹에서는 상태만 확인한다.

## 엑셀

- 입력: `.xlsx`, 첫 시트, 첫 행 제목. 학과·학번·이름 열 매핑. 최대 5MB, 10,000명. 수식 금지. 중복 학번·필수값·길이 검증. 학번 앞자리 0 유지.
- 간단 출력: 일자, 수업명, 분반, 학과, 학번, 이름, 상태, 출석시간, 처리방식, 운영/테스트 구분, 서명 시 이름.
- 서명 출력: 간단 출력 + 이미지. 서명이 없는 수동 처리·결석은 빈칸.
- 등록된 전체 명단 포함. 일자별·수업별·전체 다운로드. 엑셀 수식 주입 방지.

## 보관

출석·서명·판정·변경 이력은 자동 삭제 기한 없음. 백업도 기본 자동 삭제 없음. 출석 도중의 임시 세션과 일반 서버 로그는 영구 출석 증빙과 구분한다. 테스트 초기화는 사용자가 요청한 테스트 데이터만 삭제한다. 백업은 같은 VM 스토리지에 보관하며 디스크 손상에는 원본과 함께 소실될 수 있다.

## 테스트 환경

최초 **성공한 출석**의 학번을 같은 브라우저에 고정한다. 입력 실패는 고정하지 않으며 같은 학번으로 다른 수업에 출석할 수 있다. 학번 입력칸을 잠그고 서버에서도 다른 학번 제출을 차단한다. 운영과 테스트의 브라우저 등록은 분리된다. 시각 시나리오 변경으로는 등록이 해제되지 않으며 전체 테스트 초기화 시 해제된다. 브라우저 쿠키 삭제·별도 브라우저 사용까지 차단하는 기기 인증은 아니다.

학생 입력 화면은 수업·학번·이름·서명·제출 위주로 구성한다. 담당자 로그인과 남은 시간, 완료 화면의 다른 수업 출석 버튼은 표시하지 않는다. 반복 설명과 홍보 문구를 제거하며, 개인정보 처리 안내는 화면에서 제거하고 운영자가 QR 배포 시 별도로 고지한다. 테스트 환경 및 모의 위치 상태는 짧게 표시한다.

별도 DB, DB 계정, 서명 경로, 앱 프로세스, 쿠키, 비밀키. 운영과 같은 코드/화면/판정 사용. 모든 화면·출력에 테스트 표시. 로그인은 진행자만 필요하다.

가상수업 3개와 각 70명의 가상학생을 생성한다. 정상·접수 전·지각·종료·경계 10초 전·현재 시각 +1분·작성 세션 만료·중복 제출을 버튼으로 준비한다. 명단 불일치는 안내된 잘못된 이름으로 시험한다. 위치는 실제/모의 구역 안/밖/오차 과다/측정 실패를 지원한다. 시간 시나리오 변경은 기존 작성 세션을 무효화하되 출석 기록은 유지한다. +1분 버튼은 작성 도중 시각 이동에 사용한다.

초기화는 테스트 출석·서명·명단·수업·변경 이력을 초기화하고 가상 명단을 재생성한다. 기존 작성 세션 무효화(고정 QR 유지), 계정과 실제 위치 설정 보존. 초기화 이력 자체는 새로 기록한다. 운영 테스트 제어 URL은 404이며 운영 코드에서는 모의 시각·위치·초기화가 비활성이다.

## 타 학과 출석 및 위치·시각 표시 (2026-10-25, 타 학과 기능은 10-28부터 숨김)

- 타 학과 학생은 명단 없이 학과(100자)·학번(40자)·이름(80자)·서명을 직접 입력한다. 수업 선택은 없다.
- 학번별 한국시간 기준 하루 1회. 테스트에서는 가상 판정 시각의 날짜를 사용한다. 정상 출석으로 저장하며 수업별 지각·결석 규칙은 적용하지 않는다. 별도 행사 접수 시간 제한은 이번 범위에 포함하지 않는다.
- 수업 출석과 타 학과 출석은 별도 기록이므로 타 학과 출석이 수업 출석을 대체하지 않는다. 기존 브라우저 학번 제한은 두 유형에 공통 적용한다.
- 조교·관리자는 별도 목록에서 일자/학과/학번/이름 검색, 수동 등록·정정, 간단/서명 엑셀 다운로드를 할 수 있다. 타 학과 엑셀에는 수업명이 없다.
- 학생이 ‘출석 제출’을 누르면 현재 위치를 요청한다. 별도 위치 확인 버튼은 제공하지 않으며 권한 거부·측정 실패 시 저장하지 않는다. 브라우저가 기존 허용을 기억하면 허용 창이 다시 뜨지 않을 수 있다.
- 서버도 좌표·정확도·최신 측정 시각을 필수 검사한다. 모의 테스트는 이 검사를 통과한 후 구역·오차 등의 판정만 재현한다. 초기화 시 기본 위치 모드는 실제 위치다.
- 내 위치는 출석 완료 화면에서만 위도·경도 소수점 1자리로 표시한다. 원본 좌표는 정밀도를 유지해 반경 판정과 저장에 사용한다.
- 모든 화면의 상단에 실제 서버 현재 시각을 한국시간으로 표시한다. 브라우저 시계 대신 서버 시각을 받아 경과 시간을 표시하고 30초마다 재동기화한다. 테스트 가상 판정 시각은 별도 표시한다.
- 브라우저 쿠키 기반 학번 제한은 개인정보 보호 탭·다른 브라우저·쿠키 삭제를 넘어서는 기기 인증이 아니다.

## 학생 삭제·타 학과 기능 숨김 (2026-10-28)

- 관리자와 조교가 수업별 학생을 등록·조회·수정·삭제할 수 있다. 삭제는 해당 수업의 Enrollment 한 건에 한정한다.
- 삭제 확인 화면에 수업·학과·학번·이름과 연결된 출석·서명 수를 표시한다. 학번 확인 및 사유를 입력한 POST 요청으로 처리한다. 미리보기 이후 정보나 출석이 바뀌면 재확인을 요구한다.
- 해당 학생의 연결된 출석·서명·완료 세션을 함께 제거한다. 다른 학생·다른 수업의 같은 학번·타 학과 기록·브라우저 학번 등록·기존 감사 이력과 백업은 변경하지 않는다. 처리자·사유·삭제 범위는 감사 이력에 보존한다.
- 타 학과 메뉴와 테스트 제어의 관련 안내, 학생 화면의 소속 선택을 숨긴다. 기존 데이터·서비스·권한 있는 담당자 직접 URL은 유지한다. 숨김은 접근 권한 차단을 뜻하지 않는다.
- 표시 상태는 `config/settings.py`의 `GUEST_ATTENDANCE_VISIBLE=False`로 관리한다. 향후 True로 복원할 때 기존 기능을 다시 사용할 수 있다. 이전 브라우저 초안의 guest 선택은 숨김 상태에서 복원하지 않는다.
