# 확정 요구사항 및 화면 구성

작성 기준: 2026-10-22 사용자와 합의한 내용. 서비스 목적은 출석 전용이며 행사명·일반 안내문 설정은 제외한다.

## 목적과 운영 규모

축제 3일간 시간표에 등록된 각 수업을 별도 출석 단위로 관리한다. 종이 명단 검색과 서명으로 생기는 대기열을 줄이고 학생 스스로 출석을 완료하게 한다. 한 수업 50~70명, 동시간대 약 100~200명 집중을 예상한다. 학생에게 가입·로그인·명단 선택을 요구하지 않는다. 조교는 문제 발생 학생만 처리한다.

## 역할과 권한

|기능|학생|조교|관리자|
|---|---|---|---|
|QR 접속·본인 정보 입력·서명·위치 제출|가능|학생 흐름 체험 가능|학생 흐름 체험 가능|
|다른 학생 명단·서명 조회|불가|가능|가능|
|일정·명단·인정 구역·현장 QR 관리|불가|가능|가능|
|출석 조회·정정·엑셀·변경 이력|불가|가능|가능|
|테스트 제어·초기화|불가|가능|가능|
|계정·권한·전역 출석 정책|불가|불가|가능|
|VM 설치·삭제·백업·복구|불가|불가|서버 운영자용 스크립트|

관리자·조교는 사전 발급 계정을 사용한다. 학생 명단은 회원 계정이 아니다. 운영·테스트 계정 저장소도 분리하며 최초 관리자는 관리 스크립트로 양쪽에 생성한다. 이후 계정 변경은 각 환경에서 수행한다.

## 출석 규칙

- 수업 시작 10분 전부터 시작 15분 후까지(경계 포함) 출석.
- 시작 15분 후를 초과하고 종료 시각 전까지 지각.
- 종료 시각부터 자동 접수 불가. 종료까지 유효한 기록이 없으면 결석.
- 종료 전 미제출은 미출석으로 표시. 수동 결석 정정은 별도 명시.
- 유효한 현장 QR 접속 후 5분 작성. 제출을 서버가 받은 시점 기준.
- 작성 시간이 남아 있어도 수업 종료가 우선한다.
- 같은 학생도 수업마다 별도 제출. 같은 수업은 중복 생성·덮어쓰기 금지.
- 학번과 이름은 선택한 수업 명단에 정확히 일치해야 한다. 앞뒤 공백은 제거한다.
- QR은 1분마다 갱신. 기존 작성 세션은 QR 갱신에 영향을 받지 않는다.
- 세션이 만료되면 같은 브라우저에서 새 QR을 스캔해 작성 내용을 복원한다. 입력 복원은 해당 탭의 sessionStorage 기반이며 다른 브라우저 앱으로 열린 경우에는 보장되지 않는다.
- 화면 입력 초안은 서버 제출 전 일시 보존하며 완료 시 삭제한다. 기기 공유에 대비해 1시간 이상 된 초안은 복원하지 않는다.

## 현장 확인

관리자가 아니라 조교도 지도 중심과 반경을 설정할 수 있다. 층·강의실은 구분하지 않고 학과 건물과 주변을 인정한다. 제출할 때 위치 권한을 받아 좌표·정확도·측정 시각을 검사한다. 계속 추적하지 않는다. 실제 위치 정보가 없거나 오래됐거나 오차가 너무 크면 재측정·조교 문의를 안내한다.

QR 공유와 구역 밖 출석을 억제하는 방식이며 위치 조작·실시간 QR 전달·친구 정보 대리 입력을 완전히 차단하지 못한다. MAC 주소 수집이나 회원가입은 사용하지 않는다. 모바일 장치 고유 식별을 보장한다고 표시하지 않는다.

## 학생 화면

1. 안내/QR 접속 확인: 유효 QR만 작성 세션 발급. 만료 안내.
2. 출석 작성: 당일 수업 선택, 학번·이름, 서명, 남은 시간. 전체 명단 비공개.
3. 위치 확인·제출: 위치 권한·오류·재시도. 저장 확인 전 완료 표시 금지.
4. 완료: 수업, 학번·이름, 출석·지각, 인정 시각.
5. 오류: 시간 만료·명단 불일치·위치 실패·통신 실패 해결 안내.

## 조교 화면

로그인, 일자별 현황, 수업 등록·수정, 수업별 명단·검색·필터, 엑셀 업로드(파일→열 연결→검증/미리보기→확정), 개별 명단 수정, 인정 구역, 전체 화면 QR, 출석 상세·서명·정책 증빙, 수동 정정·사유, 엑셀 두 종류, 변경 이력, 테스트 제어.

명단 재업로드는 추가·수정 방식이다. 파일에 없는 기존 학생과 기존 출석을 자동 삭제하지 않는다. 기록이 있는 수업은 삭제 대신 접수 사용을 해제한다. 수동 정정은 기존 서명을 유지하며 없는 서명을 생성하지 않는다. 동시에 수정하면 오래된 화면의 덮어쓰기를 차단한다.

## 관리자 화면

모든 조교 화면 + 계정 발급·비활성화·역할·비밀번호 초기화 + 출석 정책 + 저장 공간·백업 목록. 행사명·일반 안내 설정 없음. 서버 백업·복구는 권한 있는 VM 운영자가 메뉴 스크립트로 수행하고 웹에서는 상태만 확인한다.

## 엑셀

- 입력: `.xlsx`, 첫 시트, 첫 행 제목. 학과·학번·이름 열 매핑. 최대 5MB, 10,000명. 수식 금지. 중복 학번·필수값·길이 검증. 학번 앞자리 0 유지.
- 간단 출력: 일자, 수업명, 분반, 학과, 학번, 이름, 상태, 출석시간, 처리방식, 운영/테스트 구분, 서명 시 이름.
- 서명 출력: 간단 출력 + 이미지. 서명이 없는 수동 처리·결석은 빈칸.
- 등록된 전체 명단 포함. 일자별·수업별·전체 다운로드. 엑셀 수식 주입 방지.

## 보관

출석·서명·판정·변경 이력은 자동 삭제 기한 없음. 백업도 기본 자동 삭제 없음. 출석 도중의 임시 세션과 일반 서버 로그는 영구 출석 증빙과 구분한다. 테스트 초기화는 사용자가 요청한 테스트 데이터만 삭제한다. 백업은 같은 VM 스토리지에 보관하며 디스크 손상에는 원본과 함께 소실될 수 있다.

## 테스트 환경

별도 DB, DB 계정, 서명 경로, 앱 프로세스, 쿠키, 비밀키. 운영과 같은 코드/화면/판정 사용. 모든 화면·출력에 테스트 표시. 로그인은 진행자만 필요하다.

가상수업 3개와 각 70명의 가상학생을 생성한다. 정상·접수 전·지각·종료·경계 10초 전·현재 시각 +1분·작성 세션 만료·만료 QR·중복 제출을 버튼으로 준비한다. 명단 불일치는 안내된 잘못된 이름으로 시험한다. 위치는 실제/모의 구역 안/밖/오차 과다/측정 실패를 지원한다. 시간 시나리오 변경은 기존 작성 세션을 무효화하되 출석 기록은 유지한다. +1분 버튼은 작성 도중 시각 이동에 사용한다.

초기화는 테스트 출석·서명·명단·수업·변경 이력을 초기화하고 가상 명단을 재생성한다. 기존 QR·세션 무효화, 계정과 실제 위치 설정 보존. 초기화 이력 자체는 새로 기록한다. 운영 테스트 제어 URL은 404이며 운영 코드에서는 모의 시각·위치·초기화가 비활성이다.
