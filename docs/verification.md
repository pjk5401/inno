## 자동 테스트 범위

### Safari 재접속 조사 (2026-10-23)

사용자 VM 조회 결과 가상학생01·02가 동일 회차 10에서 서로 다른 BrowserIdentity로 출석한 사실을 확인했다. 따라서 테스트 초기화 없이 새 브라우저 등록이 생성된 사례다. 해당 시점의 요청 쿠키 기록이 없어 브라우저 저장 문제·전달 경로 문제·서명 검증 실패를 아직 구분할 수 없다. 코드 스캐너 때문이라고 단정하지 않는다.

담당자 전용 브라우저 출석 진단 화면과 QR 접속 시 쿠키 상태 분류 기록을 추가했다. 과거 출석의 기존 연결 조회와 신규 QR 접속의 수신/검증/재사용/이전 세션/접속 호스트 조회를 제공한다. 출석 제출 없이도 최신 접속 기록을 확인할 수 있다. DB 스키마 변경은 없다. 제한 규칙을 변경하거나 식별 문제 해결을 보장하는 수정은 아니다.

운영·테스트 각각 39건, 총 78건 자동 검사 통과. 별도 세션에 기존 브라우저 쿠키만 유지한 재접속의 학번 제한, 쿠키 미수신·서명 불일치·만료 분류, 진단 권한·기존 기록 보존을 확인했다. 이후 사용자 진단 화면에서 쿠키 미수신을 확인했고, 사용자가 Safari 개인정보 보호 모드였음을 확인했다. 해당 모드의 탭별 저장 분리로 동일 기기의 새 브라우저 등록이 발생할 수 있다. 일반 모드에서 쿠키가 유지되는 범위의 제한이며 기기 인증을 보장하지 않는다.

### 현장 수동 처리 및 수업 삭제 (2026-10-23)

학생 입력·완료 화면의 학번 변경 안내와 담당자 브라우저 학번 변경 경로를 제거했다. 예외는 조교가 기존 수동 출석·정정 화면에서 처리하며 최초 브라우저 학번 제한은 유지한다. 이전 항목의 브라우저 학번 변경 기능은 이 변경으로 대체되었다.

관리자·조교가 운영/테스트 수업 목록·상세에서 삭제 확인 화면을 열 수 있다. 삭제될 명단·출석·서명 수, 엑셀 다운로드, 수업명 확인·사유 입력을 제공한다. 출석 기록까지 삭제하며 다른 수업·감사 이력·브라우저 등록은 보존한다. 확인 후 데이터 변경 시 재확인을 요구한다.

## VM에서 남은 검증

### 지도 403 수정 (2026-10-22)

전역 `same-origin` Referrer-Policy 때문에 외부 지도 타일 요청에 Referer가 빠지는 설정을 확인했다. [OpenStreetMap 타일 정책](https://operations.osmfoundation.org/policies/tiles/)에 맞춰 Leaflet 타일 이미지에만 `strict-origin-when-cross-origin`을 지정했다. 지도 서버에는 사이트 origin만 보내며 페이지 경로·쿼리 문자열은 보내지 않는다. 로그인과 나머지 요청의 전역 정책은 유지했다. 타일 로딩 오류 안내와 저작권 링크도 추가했다.

로컬 브라우저에서 동아대 주변 지도가 표시되는 것과 6개 타일 이미지의 로딩 및 개별 referrerPolicy 적용을 확인했다. 운영·테스트 설정의 기존 자동 테스트 각 26건도 통과했다. 수정본을 GitHub에 반영한 뒤 VM의 `bash manage.sh` → `7 GitHub 업데이트`로 실행 중인 운영·테스트 환경을 다시 배포하고 브라우저를 새로고침한다. VM에는 직접 배포하지 않았다.

### 환경 검증

개발 PC에는 Docker 엔진이 없어 Docker 이미지 빌드/컨테이너 실행/실제 PostgreSQL 동시성/Ubuntu 설치·백업·복구를 실행하지 못했다. 소스에 PostgreSQL 기반 GitHub Actions 테스트와 별도의 컨테이너 smoke workflow를 포함했으나 원격 저장소에 push하지 않았으므로 이 실행 결과를 주장하지 않는다.

VM에서 1→필요시 2→3→4→13 메뉴를 실행하고 다음을 확인한다.

1. 학교 HTTPS 프록시, 80포트 경로, Secure 쿠키와 로그인.
2. 운영/테스트 DB 접속 권한 격리, 서로 다른 데이터 유지.
3. 아이폰/안드로이드 실제 위치 권한 및 현장 정확도.
4. 16번 메뉴 가상학생 200명 제출 후 출석부 인원·서명·누락 점검.
5. 백업 생성/복구, 재부팅 후 자동 실행, 파일 권한.
6. 동시 운영/테스트 상태에서 메모리·CPU·디스크 점검.

위 항목은 환경 의존 검증이며 사용자 VM 테스트 전에는 운영 준비 완료로 간주하지 않는다.
