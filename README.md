# 출석 서비스

학생은 회원가입 없이 인쇄한 고정 QR로 접속해 수업 선택 → 정보 입력·서명 → 출석 제출 시 위치 확인을 거쳐 출석합니다. 수업 출석은 현재 접수 가능한 과목만 표시합니다. 타 학과 기능은 기록과 코드를 보존한 채 메뉴에서 숨겼습니다. 조교는 명단·수업·현황·예외 처리를, 관리자는 계정과 시스템 정책까지 관리합니다. 행사 소개·행사명 관리 기능은 없습니다.

## Ubuntu VM에서 시작

대상: Ubuntu, 2 CPU, RAM 4GB, 디스크 32GB, Docker 사용 가능. 외부 HTTPS 프록시는 학교에서 제공하며 VM의 HTTP 포트는 최초 설정에서 지정합니다(기본 80).

```bash
git clone <사용할-GitHub-저장소-주소> attendance
cd attendance
bash manage.sh
```

메뉴 **1 환경 점검 → 필요하면 2 인프라 설치 → 3 최초 설정 → 4 운영 실행 → 13 테스트 실행** 순서로 진행합니다. 기존 Docker가 있으면 그대로 사용합니다. 최초 설정에서 관리자 계정을 운영·테스트 각각의 DB에 생성합니다. 비밀번호는 소스에 저장하지 않습니다.

최초 설정에서 **외부 HTTPS 주소 전체**(예: `https://attendance.example.edu:8443`)와 **VM HTTP 포트**(예: `8080`)를 각각 입력합니다. 외부 포트가 기본 HTTPS 443이면 주소의 `:443`은 생략할 수 있습니다. 프록시가 VM의 지정 포트로 연결되도록 학교 클라우드 설정도 맞춰주세요.

- 운영 담당자: 입력한 주소 + `/staff/`
- 테스트 제어: 입력한 주소 + `/test/staff/test-control/`
- 테스트 담당자 로그인: 입력한 주소 + `/test/staff/login/`

**테스트 제어에서 ‘기본 테스트 준비’를 누른 뒤 ‘테스트 QR 열기’를 선택하면 교수님들이 바로 체험할 수 있습니다.** 처음에는 ‘실제 위치’ 모드입니다. 테스트 인정 구역을 설정하고 휴대폰의 위치 권한을 허용하세요. 모의 판정 모드도 실제 위치 수신은 필수입니다.

명단: 가상수업 3개, 각 70명. 학번 `20260001` / 이름 `가상학생01`부터 `20260070` / `가상학생70`까지 각자 다르게 배정합니다. 가상수업은 동일 시간에 열립니다.

## 2026-10-29 업데이트

특정 학교 주소를 기본값으로 사용하지 않습니다. 신규 VM은 **3번 최초 설정**, 이미 설정한 VM은 **17번 접속 주소 / VM 포트 변경**에서 주소 전체와 VM 포트를 지정합니다. 기존 VM은 7번 업데이트 후 메뉴를 종료하고 `bash manage.sh`를 다시 실행하면 17번이 표시됩니다.

17번은 이전 설정 파일을 보관하고 비밀번호·비밀키·DB·서명을 유지합니다. 실행 중인 환경에는 변경을 적용하며, 정지한 환경은 4번/13번으로 실행합니다. 기존 설정에 포트 항목이 없으면 종전처럼 80을 사용합니다. 접속 주소를 바꾸면 현장 QR을 다시 인쇄하세요.

## 2026-10-28 업데이트

학생 화면의 소속 선택과 개인정보 처리 안내를 제거했습니다. 개인정보 수집 고지는 운영자가 QR 배포 시 별도로 제공합니다. 타 학과 출석 메뉴·테스트 안내는 숨기되 데이터·권한 검사·조회·정정·엑셀 기능은 보존합니다.

수업·명단 목록의 학생별 **삭제**, 또는 출석 상세의 **명단 삭제**에서 해당 수업에 등록된 학생을 삭제할 수 있습니다. 연결된 출석·서명 수를 확인하고 학번과 사유를 입력합니다. 다른 수업의 동일 학생 기록·브라우저 학번 등록·기존 변경 이력은 유지합니다. 이번 변경에는 DB 마이그레이션이 없습니다. GitHub 반영 후 VM 메뉴 7번으로 업데이트하세요.

## 2026-10-25 업데이트

기존 VM은 소스를 GitHub에 반영한 후 `bash manage.sh`의 **7번 업데이트**를 실행합니다. 백업 후 운영·테스트 DB 변경을 적용하며 기존 수업·명단·출석·서명을 보존합니다. ‘현장 QR’에서 PNG 저장 또는 인쇄할 수 있습니다. QR에 담긴 주소는 운영 `/enter/`, 테스트 `/test/enter/`이며 시간이나 테스트 초기화에 따라 변경되지 않습니다. 기존 인쇄물을 교체할 때는 이번 고정 QR을 사용하세요.

서버 시각은 한국시간으로 표시됩니다. 테스트에서는 실제 서버 시각과 별도로 판정용 가상 시각을 표시합니다. 타 학과 출석 메뉴와 학생 소속 선택은 2026-10-28부터 숨김 상태입니다.

## 로컬 개발 / 자동 테스트

```bash
python -m venv .venv
source .venv/bin/activate  # Windows PowerShell: .venv/Scripts/Activate.ps1
pip install -r requirements.lock
export DEBUG=1
python manage.py migrate
python manage.py ensure_admin
python manage.py runserver
```

로컬은 SQLite를 사용합니다. 운영 Docker와 CI는 PostgreSQL을 사용합니다. `APP_ENV=sandbox`를 지정하면 로컬에서도 별도 `sandbox.sqlite3`, `/test/` 경로, 테스트 전용 서명 폴더를 사용합니다. 두 개발 서버를 띄울 때는 테스트 서버의 `PUBLIC_ORIGIN`도 해당 포트로 지정하세요.

```bash
bash scripts/check.sh
```

배포 자료에는 Python 의존성 버전, Django DB 마이그레이션, 프런트엔드 라이브러리를 고정해 포함했습니다. 서명·QR·기본 화면은 외부 CDN에서 스크립트를 받지 않습니다. 관리자 지도 배경만 OpenStreetMap 타일을 사용하며 타일 장애 시 좌표 직접 입력은 가능합니다.

운영 비밀값·실제 학생 데이터·서명·DB·백업은 GitHub에 올리지 마세요. 루트의 `.gitignore`와 `.dockerignore`가 이를 제외합니다. 이전 대화에서 중단된 `festival-check/` 템플릿은 이 프로젝트와 무관하며 배포·Git 추적에서 제외됩니다.
